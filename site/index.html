Learning Clustering / 八个模块 / Clustering for EDA

连接与分组

芯片里的分块，和通讯录里的圈子，
是同一个问题。

芯片里成千上万个单元彼此连线。把联系紧密的单元放在一起，跨组的连线就少、短、快。八个模块从“怎么给一对单元打分”走到“怎样分组才让关键路径最快”。

01 / 学习路线

八个模块

前三章讲评分与合并，LP 与谱方法给出两种产生初始分组的机制，KL/FM 改进已有分组，RW 把目标换成延迟。每章可以单独打开。

Module 02

亲和度指标

给每一对单元打分：直接边权、共同邻居、多引脚 net 的 pin-count。评分只排名，不分组。

 Module 03

贪心成对合并

从单点出发，每次合并“簇间边权和”最大的一对。数值优先、平票看名字；达到 K 或无法合并就停。

thy031 · 影片 3:10 + 2:04 + 2:42 + 2:48

 Module 04

容量约束凝聚聚类

每个簇的大小之和不能超过容量 C。装不下、走错路、合法但不最优，是三种不同的结局。

GateUltra · 影片 3:10 + 2:24 + 2:37 + 2:39

 Module 05

标签传播

每个节点看看邻居现在的标签，加入连接最强的那一组。名字不变，标签在变；它可能停下，也可能来回振荡。

Su3037 · 影片 6:20 + 2:34 + 4:54 + 2:19

 Module 06

谱二分

构造 L = D − A，取 Fiedler 向量给节点排序，在平衡窗口里逐个位置试切。翻号只交换左右。

xingguangyaoyu · 影片 3:10 + 2:02 + 2:27 + 2:57

 Module 07

Kernighan–Lin 改进

成对交换、锁定、试探，再回退到最佳前缀。试探可以变差，接受只看最好的那一段。

FanqinZeng · 影片 3:10 + 1:56 + 2:10 + 2:41

 Module 08

Fiduccia–Mattheyses 改进

一次只移动一个点，但必须保持两侧人数在窗口内。合法的才能选；试探、锁定、最佳前缀与 KL 相同。

stephQ-lab · 影片 3:10 + 1:48 + 2:21 + 2:35

 Module 09

Rajaraman–Wong 延迟导向聚类

目标换成“最长路径延迟”。跨簇一次就加 D；允许把同一个逻辑节点复制到多个簇里。

02 / 综合对比

同一张五节点图，七种不同的操作

Module 02–08 都用到课程公共图 G01，但每一章学的操作不同；Module 09 换成有向延迟模型，不使用这张图。

模块在 G01 上做什么结果这一步说明了什么
M02给 10 对节点打共同邻居分最高 A–B、D–E = 6；B–D 无直接边也得 2评分是排名，不是分组
M03K=2，从单点反复合并ABC | DE，cut 18→13→8→3每次合并 cut 恰好下降该次亲和度
M04K=2，容量 2AB | C | DE，cut 8，未达到 K下界 ⌈5/2⌉ = 3 已证明 K=2 不可能
M05A→E 异步、平票取小B/B/B/E/E，2 轮，cut 3改顺序或同步，轮数和是否停止都会变
M06Fiedler 排序 E,D,C,B,A 再扫描k=2：DE | ABC，cut 3中间那一刀（k=3）反而是 5
M07从 AE | BCD 成对交换试探 9、−8，保留 1 步，cut 12→3试探可以变差，接受看最佳前缀
M08从 AE | BCD 单点移动，人数差 ≤1D(+3)、A(+6)，保留 2 步，cut 3A 收益最大却不合法，先移 D
M09不用 G01：12 节点有向电路8 簇、20 个实例，最长延迟 8目标换成延迟，并且允许复制

几种方法在这张小图上都得到 cut 3，这只是这张图的性质。M07/M08 得到 3 也不说明它们一般能找到全局最优；M09 的“最优”只在论文的延迟模型和允许复制的前提下成立。
