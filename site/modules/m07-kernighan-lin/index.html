01 / 目标与问题

这一模块要解决什么

先看问题和成功标准，再看算法。每个目标后面的链接指向讲它的地方。

复习Module 06 给出一个二分；本章从一个已有的二分出发，通过成对交换减少 cut。为了比较公平，本章固定用同一个“坏种子” AE | BCD（cut 12）。

学习目标

  1. 说出 KL 的输入（图与人数固定的初始二分）、操作（成对交换）和输出（试探轨迹、最佳前缀、接受的分组、停止原因）。固定人数的改进问题
  2. 计算 D(v) = 外部 − 内部，以及成对收益 g = D(a) + D(b) − 2w(a,b)，解释为什么要减 2w。D 值与成对收益：为什么减 2w · [推演] D 值从哪里来 · [推演] 找到最大收益对
  3. 按“选最大收益对 → 试探交换 → 锁定 → 更新 D”走完一轮，包括收益为负的步骤（cut 暂升到 11）。一轮：试探、锁定、更新 · [解释] 为什么还要走负收益
  4. 从累计收益中选出最佳前缀（允许空前缀），区分试探状态与接受状态，并判断何时停止。最佳前缀、回退与停止 · [决策] 保留几步
  5. 逐行读懂伪代码，在 Python 中实现最大收益对与最佳前缀。逐行读懂伪代码 · [实现] 换一张图重算 · Python
  6. 说出 KL 的局限：只保持两侧人数（不是面积）、依赖初始分组、启发式不保证全局最优。局限与应用 · 实验

问题定义

输入

带权无向图；一个初始二分（两侧节点数固定，例如 AE | BCD）。

输出

每一轮的试探交换序列（收益、交换前后 cut、锁定）、累计收益、最佳前缀、接受的二分、最终 cut 与停止原因。

目标

通过成对交换减少 cut。

约束

每次交换左右各一个未锁定节点，两侧人数始终不变；每轮每个节点最多交换一次。

假设

收益可以为负；平票按 (−收益, a, b) 的字典序；最佳前缀在并列时取较短者；允许空前缀。

停止 / 完成

某一轮的最佳前缀为空（累计收益没有正值），或达到轮数上限。

§ 1固定人数的改进问题

前面的方法都在“从无到有”地产生分组。KL 换了一个问题：已经有一个二分，怎样把它改好？

设想两个机房，左边放 2 个单元，右边放 3 个，人数不能变。跨机房的连线越多，代价越大。唯一允许的操作是一对一交换：左边一个和右边一个互换位置。为了比较公平，本章固定从一个故意不太好的种子出发：

AE | BCD：跨组的边是 A–B 5、A–C 1、C–E 1、D–E 5，cut = 12。

二分种子

initial bisection

改进开始时的二分。KL 的结果依赖它。

交换

swap

左侧一个节点与右侧一个节点互换所在的组。两侧人数不变。

KL 由 Kernighan 和 Lin 在 1970 年提出，是二分改进最经典的启发式之一。原作者 FanqinZeng 用五位同学分组的虚构故事引入了“人数固定”的约束；本章保留这个约束，用课程公共图讲规则。

§ 2D 值与成对收益：为什么减 2w

外部边权

external

v 与对面节点之间的边权之和。

内部边权

internal

v 与同侧节点之间的边权之和。

D 值

D(v) = 外部 − 内部

只把 v 换到对面时，cut 会下降多少。

收益

gain

一次交换前的 cut 减去交换后的 cut。

在种子 AE | BCD 上：

节点侧外部内部D
A左5 + 1 = 60+6
B右54+1
C右1 + 1 = 24 + 2 = 6−4
D右52+3
E左1 + 5 = 60+6

交换 a（左）与 b（右）的收益：

g(a, b) = D(a) + D(b) − 2·w(a, b)

为什么要减 2w？看 E 与 D：D(E) + D(D) = 9，但两个 D 都把边 DE（5）算成了“外部边”。交换以后，E 到了右边、D 到了左边——它们仍然分处两侧，DE 依旧被切。这条边被多算了两次，所以要扣回 2 × 5：g(E, D) = 9 − 10 = −1。

六个候选对的收益：A↔D +9，E↔B +7，A↔C 0，E↔C 0，E↔D −1，A↔B −3。最大的是 A↔D（A 与 D 之间没有边，不用扣）。

§ 3一轮：试探、锁定、更新

一轮（pass）里重复：

  1. 在未锁定的左右节点对中选收益最大的一对——即使收益是负数；
  2. 交换它们（这只是试探）；
  3. 锁定这两个节点，本轮不再移动；
  4. 按新的分组重新计算 D。

G01 的第一轮：

步试探交换收益交换后的 cut累计收益
1A↔D+93+9
2E↔C−811+1

第 2 步时只剩 E（左）与 B、C（右）未锁定：E↔C −8、E↔B −13，全是负数。KL 不在这里停下，而是照样选最大的 E↔C，cut 暂时升到 11。左侧再没有未锁定的点，本轮试探结束。

为什么要走负收益

在这张小图上第 2 步只会变差；但在更大的图上，先变差的一步可能“打开”后面更大的正收益。只有把一整轮走完，才能看清所有前缀，再决定保留几步。

§ 4最佳前缀、回退与停止

前缀

prefix

一轮试探序列中从第 1 步起连续的前 k 步。

最佳前缀

best prefix k*

累计收益最大的前缀；k = 0（什么都不做）也是候选。

试探 / 接受

trial / accepted

试探状态是一轮中途的临时分组；接受状态是从本轮起点只应用前 k* 步得到的分组。

第一轮的累计收益：k = 0 → 0，k = 1 → +9，k = 2 → +1。最大的是 k* = 1：从本轮起点只应用 A↔D，接受 ABC | DE，cut 3。第 2 步被撤回——它只是为了看清后面还有没有更好的。

第二轮从 ABC | DE 出发，所有节点解锁：试探 E↔C −8，D↔B +2，累计 −8、−6。都不如什么都不做：**空前缀 k* = 0 胜出**，cut 保持 3，算法停止。

§ 5逐行读懂伪代码

  1. repeat:
  2. start ← 当前二分；trial ← start
  3. while 两侧都有未锁定的节点:
  4. 计算所有未锁定节点的 D = 外部 − 内部
  5. (a, b) ← 未锁定跨侧对中 g = D(a)+D(b)−2w(a,b) 最大者
  6. 在 trial 中交换 a、b；锁定 a、b
  7. k* ← 累计收益最大的前缀（允许 k* = 0）
  8. 当前二分 ← 从 start 只应用前 k* 步
  9. until k* = 0

点击任一行看解释；在实验中单步时，当前执行的行会自动高亮。

和 Python 的对应：第 4–5 行 → best_swap()；第 7 行 → best_prefix()；第 1–9 行 → kernighan_lin()。

§ 6局限与应用

  • 启发式：G01 上恰好到达 cut 3，不说明 KL 一般能找到全局最优；它可能停在局部最优。
  • 依赖种子：从不同初始二分出发，结果可能不同；比较方法时要用同一个种子。本模块的种子与 Module 08 相同。
  • 只保持人数：一换一保持两侧节点个数，不保持面积。
  • 代价：朴素实现每一步都要枚举所有未锁定的跨侧对。
  • 工程含义：KL 与下一模块的 FM 都常用来在谱方法或其他初始划分之后做局部改进。改一条边的权重就要重算所有 D 值——例如把 A–B 从 5 改成 1，初始 cut 变为 8，A↔D 的收益变为 5。

07 / Python 实现轨道 · 可选

实现最大收益对与最佳前缀

网页基础轨道不需要 Python。下载后在任意空目录运行；只用标准库。

任务（starter.py）：

  1. best_swap(adj, side, locked)：在未锁定的左右节点对中找收益最大的一对（收益可为负）。
  2. best_prefix(gains)：返回 (k, 累计收益)，k = 0 合法。

提示一：先算每个节点的 D = 外部 − 内部，再对每一对算 D(a) + D(b) − 2w(a,b)。

提示二：前缀必须从第 1 步起连续；只在累计收益严格变大时更新 k。检查器会在 120 个随机图上检查：两侧人数不变、每点每轮最多交换一次、收益 = 交换前后 cut 之差。

08 / 常见错误与局限

容易错在哪里

每条都给错误结果、错因、反例和修正；反例的数值都由测试复算。

忘记减 2w

错误结果
g(E, D) = D(E) + D(D) = 6 + 3 = 9，以为 E↔D 很划算。
错因
两个 D 都把边 DE 算成了外部边；交换后 E、D 仍分处两侧，这条边依旧被切，被多算了两次。
反例 / 证据
g(E, D) = 9 − 2×5 = −1；真正的最佳对是 A↔D（A、D 之间没有边），g = 9。
修正
g = D(a) + D(b) − 2w(a, b)。

遇到负收益就停

错误结果
第一轮做完 A↔D 后看到剩下的收益全是负数，就结束本轮。
错因
KL 要走完整轮，才能比较所有前缀；在更大的图上，先变差的一步后面可能出现更大的正收益。
反例 / 证据
G01 第一轮第二步 E↔C 收益 −8，cut 暂升到 11——这一步只是试探，最终会被撤回。
修正
继续试探直到没有未锁定的跨侧对，再选最佳前缀。

把任意几个正收益步当作“前缀”

错误结果
从一轮的试探里挑出所有正收益的步骤一起应用。
错因
后面的收益是在前面步骤已经做过的情况下算的；跳过中间某一步，后面的收益就不再成立。
反例 / 证据
第二轮的试探收益是 −8、+2：单独取 +2 的那一步，并不能从起点得到 +2 的改善。
修正
只取从第 1 步开始的连续前缀；累计收益最大处为 k，k = 0 合法。

把试探状态当成结果

错误结果
报告第一轮结束时的 cut 11。
错因
一轮结束时的状态是全部试探都做完的状态；接受的是回退到最佳前缀后的状态。
反例 / 证据
第一轮试探结束 cut 11，接受的是前 1 步：ABC | DE，cut 3。
修正
分开显示 trial 与 accepted；只报告 accepted。

以为人数平衡就是面积平衡

错误结果
单元面积不同时，仍认为 KL 交换保持了两侧面积。
错因
KL 一换一只保持两侧的节点个数。
反例 / 证据
一个大单元与一个小单元互换，人数不变，面积会变。
修正
需要面积约束时另加检查，或使用支持加权平衡的方法；不要套用 Module 04 的 capacity 字段假装等价。

适用范围与局限

  • KL 是启发式：G01 上得到 cut 3 只说明这张图；一般不保证全局最优。
  • 结果依赖初始二分；比较方法时从同一个种子出发才公平。
  • 只保持两侧节点数，不保持面积。
  • 朴素实现每一步枚举所有未锁定的跨侧对，一轮约 O(n³)；实际实现会维护排序的 D 值。
  • 只适合两侧人数固定的二分；下一模块的 FM 用单点移动和平衡窗口放宽这一点。
