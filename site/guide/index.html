如何挑战

每个模块的挑战都按同一流程进行。它们检查的是“能否用规则算出结果并解释”，不是“有没有看完视频”。

  1. 读任务：每题开头写着 [类别] 题名、难度，以及“这题检查什么”。
  2. 先预测：在动手前写下你认为的答案。很多题故意挑了容易猜错的地方（例如没有直接连线的节点对也有分数）。
  3. 操作：填数字、选选项、点选节点或边、给列表排序。需要时可以去上方的实验里单步验证。
  4. 提交：判定来自本页同一个算法引擎或明确规则。分组题不在乎组的名字和左右顺序，只看谁和谁在一起。
  5. 看解释：答对后会显示“为什么”；答错时会告诉你违反了哪条规则。
  6. 再试：“提示”有两级——先给方向，再给具体关系。“重置重试”会清空本题记录。

记录怎么算

状态含义
未开始还没提交过
尝试中提交过但还没答对
独立完成没看答案就答对
看过答案后完成看过答案与解析之后答对

看答案不扣分，也不会锁题。两种完成方式分开记录，只是为了让你知道哪些是自己做出来的。记录保存在本机浏览器里（localStorage），可以在学习记录导出或导入。浏览器禁止存储时，页面仍然可用，只是关闭后不保留。

类别与难度是两回事

类别说明题目的用途：概念（区分两个容易混的东西）、推演（按规则手算一步）、探索（改参数看变化）、约束（检查合法性）、纠错（找出错误说法）、解释 / 决策（说明为什么这样选）、实现（与 Python 练习对应）、应用（放回 EDA 场景）。难度另标“入门 / 练习 / 挑战”。同一类别可以有不同难度。

两个需要额外说明的操作

  • Module 02 手工排序：用每行的 ↑ ↓ 按钮（或 Tab 加回车）调整顺序，排好后提交。
  • Module 08 回退：题目给出一轮试探的累计收益，你要选出保留前几步；“保留 0 步”也是合法答案。
