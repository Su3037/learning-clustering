基础速查：图、边权、net、cut、簇

这页是八个模块共用的最少前置知识。每个模块第一次用到某个概念时还会再展开一次；这里给统一的定义，让各章不必重复同一段开场。

为什么芯片设计要“分组”

芯片里有成千上万个单元，彼此用导线连接。把连接紧密的单元放进同一块区域，跨区域的导线就更少、更短。更少的长导线意味着更少的布线拥塞，信号也更快。聚类（clustering）先把单元分成若干组，再交给后续的划分、布局工具处理。

用图描述连接

  • 节点（node）：一个电路单元。图上的坐标只为了画图。
  • 边（edge）与边权（weight）：两个单元之间有连接就连一条边；边权表示连接强度，例如两者之间的连线数量。权重越大，越希望它们在同一组。
  • net（信号网）：一个信号可以同时连到三个或更多单元的引脚。把它画成普通边需要一个模型，例如“团（clique）模型”把它展开成所有两两之间的边，并把权重摊薄。Module 02 和 08 会讲这件事。

分组和代价

  • 簇（cluster）：被分在一起的一组单元。
  • 划分（partition）：每个单元恰好属于一个组。Module 09 允许复制单元，所以那里的结果不再是严格的划分。
  • cut（割边权和）：两端分在不同组的边，把它们的权重加起来。每条无向边只算一次。
课程公共图 G01

节点 A–E，每个大小为 1；边 AB=5、AC=1、BC=4、CD=2、CE=1、DE=5，总权 18。分组 ABC | DE 只切断 CD=2 和 CE=1，cut = 3。种子分组 AE | BCD 的 cut = 12。Module 02–08 都会用这张图，但每章做的事不同：评分、合并、容量、标签、谱、交换、单点移动。同一个 cut 3 出现在几章里，不说明这些算法等价。

Python 轨道怎么用

每个模块都有一个可下载的练习包：starter.py（留有 TODO）、check.py（检查器）、reference.py（参考实现）、fixtures/（例子数据）、README.md。在任意空目录解压后运行：

python3 check.py              # 检查你写的 starter.py
python3 check.py reference.py # 参考实现应全部 PASS

未完成的函数报 INCOMPLETE，不会算作通过；缺少可选依赖的检查报 SKIP，同样不算通过。网页上的实验和挑战都不需要安装 Python。
