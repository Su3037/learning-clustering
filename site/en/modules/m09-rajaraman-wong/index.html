Problem statement

Input

A combinational DAG (no cycles), each node’s delay δ(v) and size s(v), the cluster capacity M and the inter-cluster delay D; PIs are the nodes with no inputs, POs are the outputs.

Output

Each node’s label l(v), the selected clusters, the physical instances and the wires between them, each PO’s arrival time and the largest delay, the replicated nodes and the total area.

Objective

Minimise the largest path delay from any PI to any PO.

Constraints

Each cluster’s total size ≤ M; wires inside a cluster add 0 delay, wires between clusters add D; every instance must have complete inputs.

Assumptions

Logic nodes may be replicated (the premise of the optimality result); this course’s example has δ = 1 and s = 1; ties: when l(x) + Δ(x, v) is equal, the later node in topological order comes first (a candidate assumption).

Stopping

Labelling ends when every non-PI node is processed; recovery starts from the POs and ends when every needed cluster exists. A cyclic input is an error, with no approximation.

§ 1The goal has changed: from cut to delay

The previous seven modules all reduced the cut: the fewer wires between groups, the better. On a chip, though, what often matters more is speed: as a signal travels from input to output, the slowest path decides how fast the circuit can run.

Put the circuit into separate clusters (for example different chip regions or devices), and wires between clusters are much slower than wires inside one. So the question becomes: how should we cluster so that the delay of the longest path is as small as possible?

Start with the simplest chain: P → X → Y → O, each node with delay 1, each crossing between clusters adding D = 3, and at most 2 nodes per cluster.

SplitCrossings on the pathDelay
{P, X} | {Y, O}1 (X→Y)4 + 3 = 7
{P} | {X, Y} | {O}2 (P→X, Y→O)4 + 3 + 3 = 10

Both splits respect the capacity, yet the delays differ by 3. Delay depends only on how many boundaries the longest path crosses, not on how many wires are cut in total. On a branching circuit, two splits can cut the same number of wires while the critical path crosses a different number of boundaries.

§ 2The model: DAG, delay, capacity

directed acyclic graph

DAG

A combinational circuit: signals flow along directed edges, with no cycles. This chapter does not use the earlier undirected five-node graph.

primary input / output

PI / PO

Source nodes with no inputs / the circuit’s outputs.

node delay

node delay δ(v)

The time a signal needs to pass through node v. In this chapter’s example, δ = 1.

inter-cluster delay

inter-cluster delay D

The fixed extra delay of a wire whose two ends are in different clusters; 0 inside a cluster. It has nothing to do with the degree matrix D of Module 06.

cluster capacity

capacity M

The upper limit on a cluster’s size. In this chapter’s example each node has size 1 and M = 4.

A path’s delay = the sum of δ over the nodes on it + D × the number of crossings. The circuit’s delay = the largest over all PI→PO paths.

Background: Lawler, Levitt and Turner (1969) studied module clustering under unit delay; Rajaraman and Wong proposed an algorithm for general node delays at DAC 1993, published in IEEE TCAD in 1995, and proved that when nodes may be replicated it finds a clustering whose largest delay is minimal.

§ 3Replication: one logic node, several instances

logic node

logicalId

A gate or cell of the circuit (for example b).

physical instance

instanceId

A copy of a logic node placed in some cluster, written “node@root” in this course (for example b@d).

replication

replication

Placing an instance of the same logic node in several clusters. Every instance needs complete inputs.

Why replicate? If one node feeds two delay-critical clusters, putting it in one of them makes the other fetch the signal across a boundary, paying D. With a copy, both clusters get it from inside.

Replication is not free, and a “node → cluster” map cannot express it

Every copy takes area. The 12 logic nodes of the candidate example end up as 20 instances. As a data structure, a “node → cluster” map gives each node a single cluster; after replication, logic nodes and instances must be recorded separately, and every instance’s inputs checked for completeness. The course engine’s instances[{instanceId, logicalId, clusterId}] and instance wires exist for exactly this.

§ 4Initialisation: the longest node delay Δ

The candidate example (reconstructed from a figure in the original author muranfei’s film, candidate status) has 12 nodes a–l: PIs a, b, c, POs k, l, and 15 directed edges.

Δ(x, v): over all paths from x to v, the largest sum of node delays, counting v but not x. Undefined when there is no path.

For example, b → e → g → i → k passes through e, g, i and k: Δ(b, k) = 4. The original film shows the full Δ table at 438 s; this course recomputes it from the reconstructed edge list, and the two agree entry by entry.

A PI’s label is its own delay: l(a) = l(b) = l(c) = 1.

§ 5Labelling: l(v) = max(l1, l2)

Process each non-PI node v in topological order:

  1. For each ancestor x of v, compute l(x) + Δ(x, v): “if everything before x is as fast as possible, how long does the signal take to get from x to v”.
  2. Sort by this value, largest first (on a tie, this course assumes the later node in topological order comes first: a candidate assumption).
  3. Put v and the leading ancestors into the candidate cluster, in order, up to capacity M.
  4. l1 = the largest value among the PIs inside the cluster; l2 = the largest value among the ancestors outside + D. l(v) = max(l1, l2).

Take i (capacity 4):

Ancestor xl(x) + Δ(x, i)Inside?
g3 + 1 = 4yes
e2 + 2 = 4yes
c1 + 3 = 4yes (PI)
b1 + 3 = 4no
f, d, a3no

l1 = 4 (the PI c inside), l2 = 4 + 3 = 7 (b is the largest outside). l(i) = 7. Finally l(k) = l(l) = 8.

Two kinds of “label”

RW’s l(v) is a time; Module 05’s label is a group tag. The name is the same; the meaning is entirely different.

§ 6Recovery: working back from the outputs

Labelling only gives each node a candidate cluster. The clusters actually used are found by working back from the POs:

  1. Start from k and l and take their candidate clusters: k’s {g, i, j, k}, l’s {e, g, j, l}.
  2. The inputs from outside (k’s cluster needs d, e, f, h; l’s cluster needs b, c, h) each become a new root, and their candidate clusters are taken.
  3. Repeat until no new cluster is needed.

The candidate example gives 8 clusters and 20 instances; g, j, e and a have 2 instances each, b and c 3 each. Every instance has complete inputs (the course tests check this). Both outputs arrive at time 8, equal to their labels.

Compared with no replication: with the same capacity 4 and D = 3, if each node may sit in only one cluster, this course’s exhaustive search over every legal grouping gives a best largest delay of 10. Replication spends 8 extra instances to buy 2 units of delay.

§ 7Pseudocode

  1. check the input is a DAG; topological order; compute Δ(x, v)
  2. for each PI p: l(p) ← δ(p)
  3. for each non-PI node v (topological order):
  4. score(x) ← l(x) + Δ(x, v), for each ancestor x of v
  5. candidate cluster ← v + ancestors by score, descending, up to M
  6. l1 ← largest score of a PI inside; l2 ← largest score outside + D
  7. l(v) ← max(l1, l2)
  8. from the POs back: take candidate clusters; outside inputs become new roots
  9. make an instance per (root, member); connect the instance wires

Click any line for its explanation. When you step through the lab, the line being executed lights up.

How it maps to Python: line 1 → topological_order(), longest_node_delays(); lines 2–7 → rw_label(); lines 8–9 → rw_reconstruct(); arrival times → evaluate_instance_delay().

§ 8Limits and open questions

  • Optimality only within the model: a DAG, node delays, 0 inside a cluster, a fixed D between clusters, capacity, and replication allowed. If replication is forbidden, or area, pins or power must also be optimal, the result does not carry over. This course’s tests check the implementation’s consistency; they do not prove optimality.
  • Candidate data: the 12-node example is reconstructed from frames of the original film; “on a tie, reverse topological order first” is an assumption. It reproduces 8 clusters, 20 instances and output 8, but the original edge list and tie rule await the original author’s confirmation.
  • Course mapping: this submission is numbered Lesson 9, while Lab 09 in the teacher’s catalogue is Multilevel. This module keeps RW as submitted, does not replace Multilevel, and the correspondence awaits the teacher’s confirmation.
  • In engineering: delay-driven clustering is used when a circuit is split across chips or FPGA regions, to reduce the delay between regions; replication buys speed and costs area.

08 / Common mistakes and limits

Where it goes wrong

Each entry gives the wrong result, the cause, a counterexample and the fix; every number in the counterexamples is recomputed by the tests.

Thinking a small cut means a small delay

Wrong result
Choose the split with the fewest wires between clusters and assume the critical path is fastest.
Why
Delay depends only on how many boundaries the longest path crosses; the total number of cut wires does not decide it.
Counterexample
Splitting the chain as {P,X} | {Y,O}: 1 cut wire, delay 7; as {P} | {X,Y} | {O}: 2 cut wires, delay 10. On a branching circuit, two splits with the same number of cut wires can cross the critical path a different number of times.
Fix
Compute delay per path: the sum of node delays + D × the crossings on the path, and take the largest over all PI→PO paths.

Representing replication with a “node → cluster” map

Wrong result
Give each node one cluster number, and write the same node into two clusters when copying.
Why
A map gives each node one cluster only; after replication one logic node has several physical instances, each with its own inputs.
Counterexample
In the candidate graph logic node b has 3 instances: b@b, b@d, b@e.
Fix
Keep logic nodes and instances apart: instances[{instanceId, logicalId, clusterId}] plus the instance wires, and check that every instance has complete inputs.

Treating replication as free

Wrong result
Copy nodes freely to shorten the delay.
Why
Every copy takes area; RW’s result is delay-optimal given replication and capacity, not area-optimal.
Counterexample
Candidate graph: 12 logic nodes become 20 instances, total area 20.
Fix
Report the instance count and total area; compare solutions on delay and cost together.

Extending “delay-optimal” to the no-replication case

Wrong result
Believing RW’s optimality still holds when replication is forbidden.
Why
The optimality proof relies on replication being allowed; without it the problem is different and the result no longer applies.
Counterexample
On the candidate graph with no replication and capacity 4, exhaustive search gives a best largest delay of 10, while RW with replication gives 8.
Fix
State the premises: a DAG, the node-delay model, a fixed D, capacity, replication allowed.

Taking RW’s “label” for an LP label

Wrong result
Thinking l(v) is the group v belongs to.
Why
RW’s label is a number: the smallest possible arrival time from the inputs to v (within the model); an LP label is a group tag.
Counterexample
In the candidate graph l(i) = 7 and l(k) = 8, both times.
Fix
Call it the “delay label l(v)”, and keep it apart from Module 05.

Scope and limits

  • The optimality comes from the paper (Rajaraman and Wong, IEEE TCAD 1995; conference version DAC 1993) and holds only within its model: a combinational DAG, node delays, 0 inside a cluster, a fixed D between clusters, a capacity constraint, and replication allowed. This course’s tests do not prove optimality; they check that the instance graph is legal and that the arrival times are computed consistently.
  • The 12-node example is a candidate reconstruction: the figure and Δ table in the original film give 15 edges, which under the tie assumption “l descending, then reverse topological order” reproduce 8 clusters, 20 instances and output 8. The original edge list and tie rule await the original author’s confirmation; they are not data confirmed by the teacher.
  • The course mapping awaits confirmation: Lab 09 in the teacher’s catalogue is Multilevel, and this module does not replace it.
  • This implementation assumes unit sizes and adds candidates one at a time (a prefix); the packing strategy for general sizes, and the paper’s details there, need further checking.
  • Replication costs area; real designs also weigh pins, power and more, which this chapter does not cover.
