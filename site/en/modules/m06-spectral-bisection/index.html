01 / Goals and problem

What this module solves

Start with the problem and what counts as success, then the algorithm. Each goal links to where it is taught.

RecapModule 05 的标签传播只看邻居；本章用整张图的信息：一个矩阵，一个特征向量，一条数轴。

Learning goals

  1. 说明二分问题为什么必须声明“两组非空”和平衡窗口，并算出 5 个节点的非空无标签二分数 15。二分：为什么必须声明“非空”与“平衡” · [纠错] 有多少种非空二分
  2. 从边权构造未归一化拉普拉斯矩阵 L = D − A，检验对称与每行和为 0（A 行：6, −5, −1, 0, 0）。从边权到拉普拉斯矩阵 · [概念] 写出 L 的一行
  3. 用二次型 xᵀLx = Σ w(u,v)(x_u − x_v)² 解释“连得紧的节点数值接近”；弹簧只作类比。二次型：为什么连得紧的点数值接近
  4. 说明 λ1 = 0、Fiedler 向量的条件（连通、λ2 简并）与翻号等价。Fiedler 向量与它的条件 · [探索] 翻号会改变结果吗 · [实现] 断开的图
  5. 按 Fiedler 排序 E, D, C, B, A 扫描切分（cut 6, 3, 5, 6），在 40/60 窗口内选 k = 2。排序扫描：在窗口里试每一刀 · [推演] 不在中间切
  6. 纠正三个常见误解（16 vs 15、无约束必切单点、存储向量当求解器），并在 Python 中做数值自检。三个常见误解的更正 · 伪代码与数值自检 · [纠错] 无约束一定切单点吗 · Python

Problem statement

Input

非负权无向图；平衡窗口（例如每组占 40%–60% 的节点）。

Output

两组节点、cut、Fiedler 排序、每个扫描位置的 cut 与合法性，以及数值诊断（λ、残差、连通性、简并）。

Objective

在平衡窗口内找 cut 尽量小的二分；Fiedler 排序提供一组候选切分位置。

Constraints

两组都非空；每组大小在窗口内；只在排序的相邻位置之间切（共 n − 1 个候选）。

Assumptions

未归一化 L = D − A（D 为度矩阵）；连通图；排序平票按节点名；向量整体翻号视为同一结果。

Stopping

扫描完全部 n − 1 个位置后，在合法位置中选 cut 最小者。谱方法给出的是好的候选，不保证全局最优。

03 / Lesson · from intuition to pseudocode

From an example to pseudocode

Section numbers match the film chapters and slide pages; the full map is in the crosswalk at the end of this page.

01二分：为什么必须声明“非空”与“平衡”02从边权到拉普拉斯矩阵03二次型：为什么连得紧的点数值接近04Fiedler 向量与它的条件05排序扫描：在窗口里试每一刀06三个常见误解的更正07伪代码与数值自检

§ 1二分：为什么必须声明“非空”与“平衡”

二分（bisection）把节点分成两组。如果只追求 cut 最小，有一个毫无用处的答案：把所有节点放进同一组，cut = 0。所以问题必须先写清：

  1. 两组都非空；
  2. 不区分左右——ABC | DE 与 DE | ABC 是同一个分法；
  3. 平衡窗口：每组的大小必须在某个范围内，例如占全部节点的 40%–60%。

在这些约定下，5 个节点一共有多少种分法？2⁵ = 32 种“每个节点贴左或右”的标记中，去掉“全在左”“全在右”两种，再除以 2（左右交换算一种）：

(2⁵ − 2) / 2 = 15

原题库的 16

原作题库写的是 16。差的那一种，就是“一组为空、另一组是全集”。本课程穷举 G01 的非空无标签二分，测试断言恰好 15 种。

穷举 15 种对 5 个节点还可以，节点一多就不现实。谱二分的想法是：先给每个点一个数，把它们排成一条线，只在线上的相邻位置之间切——n 个节点只有 n − 1 个候选。

§ 2从边权到拉普拉斯矩阵

度

degree d(v)

与 v 相连的边权之和。A 的度 = 5 + 1 = 6。

邻接矩阵

adjacency matrix A

A[u][v] = w(u, v)，没有边为 0。

拉普拉斯矩阵

Laplacian L = D − A

对角线放度数，非对角放负的边权。本章的 D 是度矩阵，不是 Module 09 的跨簇延迟 D。

每条无向边 (u, v, w) 对 L 做四处贡献：L[u][u] += w，L[v][v] += w，L[u][v] −= w，L[v][u] −= w。G01 的 L（行列顺序 A–E）：

ABCDE
A6−5−100
B−59−400
C−1−48−2−1
D00−27−5
E00−1−56

两个自检：L 对称；每行和为 0（对角的度数正好等于这一行负边权之和）。行和为 0 意味着全 1 向量满足 L·1 = 0：λ = 0 永远是 L 的特征值。

§ 3二次型：为什么连得紧的点数值接近

给每个节点一个数 x_v。L 有一个关键性质：

xᵀLx = Σ w(u, v)·(x_u − x_v)²，求和对每条无向边一次。

如果让 x 只取 +1（左组）或 −1（右组），被切断的边贡献 w·(2)² = 4w，没被切断的贡献 0——所以 xᵀLx = 4·cut。ABC | DE 的指示向量给出 4 × 3 = 12。

最小化 cut 很难，因为 x 只能取 ±1。谱方法把这个条件放松：允许 x 取任意实数，只要求它不是常数向量（与全 1 正交）、长度固定。放松后的最优解就是第二小特征值 λ2 对应的特征向量。

弹簧类比（仅限这里）

可以把每条边想象成一根弹簧，边权越大弹簧越硬；xᵀLx 像是所有弹簧被拉伸的总“能量”。连得紧的节点被硬弹簧拉近，数值相近。这只是帮助理解二次型的比喻：本页没有运行任何物理模拟，边权也不是真的硬度；其他模块的算法与弹簧无关。

§ 4Fiedler 向量与它的条件

特征值 / 特征向量

eigenvalue / eigenvector

满足 Lx = λx 的数 λ 与非零向量 x。

Fiedler 向量

Fiedler vector

第二小特征值 λ2 的特征向量（读作“菲德勒”）。λ2 也叫代数连通度。

G01 的特征值（本页浏览器实时求解，与 NumPy 对照一致）：

λ1 ≈ 0，λ2 ≈ 1.7733143437，λ3 ≈ 8.455，λ4 ≈ 11.605，λ5 ≈ 14.166

Fiedler 向量（统一符号，使 A 为正）约为 A 0.519，B 0.418，C 0.106，D −0.489，E −0.553。

使用它要注意三个条件：

  • 连通：图连通时 λ1 = 0 只有一个；图断开时 λ2 也是 0，向量只告诉你“哪些点在同一个连通分量”。
  • 简并：如果 λ2 = λ3，第二特征向量不唯一，任何该特征空间中的方向都同样合法，排序可能不同。
  • 翻号：x 是特征向量，−x 也是。整体翻号只让排序反向、左右互换，分组不变。

§ 5排序扫描：在窗口里试每一刀

按 Fiedler 值从小到大排序：E, D, C, B, A。在相邻位置之间切，前 k 个为一组：

k左组右组cut40/60 窗口（每组 2–3 个）
1ED C B A6不合法
2E DC B A3合法
3E D CB A5合法
4E D C BA6不合法

窗口内 k = 2 的 cut 最小，结果 DE | ABC，cut 3。注意两点：

  • “切在正中间”（k = 3）并不更好：cut 是 5。
  • 在这张图上，正负号的分界恰好也在 k = 2；但一般情况下正负号并不保证落在窗口内，所以要扫描。

原作者的页面让学生亲手选择 k 并实时看到 cut——本章实验保留了这一操作。

§ 6三个常见误解的更正

  1. 二分数是 15，不是 16（见第 1 节）。
  2. 无平衡约束时，最优不一定是孤立一个点。 孤立一个点的 cut 等于它的度数：A 6、B 9、C 8、D 7、E 6，最小是 6；而 ABC | DE 只有 3。正确的说法是：没有约束时可能出现过小的分组，所以要声明窗口。
  3. 预计算向量不是求解器。 原作页面存储了三位小数的向量，改 k 会实时算 cut，但改图不会重算向量。三位小数向量的残差 ‖Lx − λx‖/‖x‖ 约 0.0044——这是舍入造成的，不是求解失败。本课程在浏览器中用 Jacobi 旋转实时求解（残差约 10⁻¹⁵），并保留原值作对照。

§ 7伪代码与数值自检

  1. L ← D − A
  2. (λ, x) ← L 的特征分解，升序排列
  3. 检查 λ1 ≈ 0、连通、λ2 是否简并、残差
  4. f ← λ2 的特征向量，统一符号
  5. order ← 节点按 f 升序，平票按名字
  6. for k = 1 … n−1: 左 = order[:k]，算 cut
  7. 返回窗口内 cut 最小的 k

Click any line for its explanation. When you step through the lab, the line being executed lights up.

和 Python 的对应：第 1 行 → laplacian()；第 2 行 → 已提供的 jacobi_eigen()；第 6–7 行 → sweep() 与 spectral_bisection()。检查器还会核对残差、翻号等价、断开图 λ2 = 0。

在 EDA 中，谱方法常用来给大规模划分一个全局视角的初始解，之后交给 KL/FM 这类局部改进方法——这正是下面两个模块。

08 / Common mistakes and limits

Where it goes wrong

Each entry gives the wrong result, the cause, a counterexample and the fix; every number in the counterexamples is recomputed by the tests.

把 5 个节点的二分数算成 16

Wrong result
原题库：“5 个节点分成两组共 16 种”。
Why
2⁵ = 32 种左右标记里，有 2 种是“一组为空”，再除以 2 去掉左右交换：(32 − 2) / 2 = 15。16 把空组/全集那一对也算进去了。
Counterexample
穷举 G01 的非空无标签二分：恰好 15 个（本课程测试断言）。
Fix
先说清“两组都非空、不区分左右”，再计数。

以为没有平衡约束时最优一定切出单点

Wrong result
原文：“无平衡约束，答案永远是切掉一个点”。
Why
孤立一个点的 cut 等于它的度数；这张图上最小的单点 cut 是 6，而 ABC | DE 只有 3。
Counterexample
G01 无约束最小 cut 是 ABC | DE = 3，不是单点。
Fix
改为“可能出现过小的分组”，所以要声明平衡窗口。

把 Fiedler 的正负号当成平衡的分法

Wrong result
直接按正负号切，认为两边一定差不多大。
Why
正负号只是一个阈值；它不保证两组大小在窗口内，也不代替扫描。
Counterexample
在 G01 上正负号恰好切在 k = 2；换别的图，正负号可能切出 1 : n−1。
Fix
按排序逐个位置扫描，只在窗口内的位置里选最小 cut。

把存储的三位小数向量当成求解器

Wrong result
原页面改 k 时会实时算 cut，但特征向量是写死的三位小数；改图后仍用旧向量。
Why
向量由预先计算得到，改图不会重算；三位小数的残差约 0.0044，只够展示。
Counterexample
本课程实时求解的残差约 10⁻¹⁵；存储向量的残差 0.0044。两者在 G01 上排序相同。
Fix
标明“预计算”，或像本课程一样在浏览器里真的求解并显示残差。

以为翻号会改变结果

Wrong result
两次运行得到的向量正负相反，就认为分组不同。
Why
若 x 是特征向量，−x 也是；排序整体反向，同一刀两侧互换名字。
Counterexample
G01 上 x 与 −x 都切出 DE | ABC，cut 3。
Fix
比较分组时不区分左右。

Scope and limits

  • 谱二分给出一个“好的候选”，不保证全局最优；它常作为划分的初始解，交给 Module 07/08 改进。
  • 本章用未归一化 L；归一化拉普拉斯等变体会给出不同的排序。
  • 图不连通时 λ2 = 0，特征向量只反映连通分量；λ2 简并时方向不唯一。
  • 浏览器内的 Jacobi 求解适合教学规模（本页限制 40 个节点）；大规模问题用稀疏迭代方法（如 Lanczos）。
  • 弹簧比喻只帮助理解二次型；本页没有运行任何物理模拟。
