Glossary

Terms and symbols

Each term is explained in the first module that needs it; this page gives the shared Chinese and English names and what not to confuse it with. The same letter can mean different things in different modules (for example the degree matrix D in spectral methods and the inter-cluster delay D in RW).

TermMeaningDo not confuse withFirst explained
Module
模块		本课程的学习单元，Module 02–09。原 Lab、Lesson、Issue 编号只作来源映射，不是学习单元的名字。M02
node / cell
节点 / 电路单元		图中的一个点；在 EDA 中通常代表一个标准单元或模块。图中节点的坐标只是为了画图，不代表芯片上的真实位置。M02
edge / weight
连边 / 边权		两个节点之间的连接；边权表示连接强度（例如连线数量或信号重要性），每门模块都声明它的含义。边权不是物理硬度，也不是距离；权重越大通常表示越该放在一起。M02
net / pin
信号网 / 引脚		一个 net 把多个单元的引脚连成同一信号；可以有两个以上的端点。多引脚 net 不等价于一条普通边；展开成“团”是一种近似模型。M02 M08
affinity
亲和度		在指定模型下给一对节点（或一对簇）的“应该放在一起”的评分。不是概率，也不是距离；不同模块用不同亲和度，甚至不用亲和度（LP、谱、KL/FM）。M02 M03
cluster
簇		一组被分在一起的单元。是否允许同一单元出现在多个簇里（复制）要看算法：只有 RW 允许。M03
partition
划分		把所有节点分成互不重叠、合起来覆盖全部节点的若干组。RW 复制以后，逻辑节点可以出现在多个簇中，结果不再是互斥的划分。M03 M09
cutsize / cut
割边权和		两端在不同组的边的权重之和；每条无向边只算一次。不是被切的边条数；超图的 hypercut 按 net 计，和图的 cut 不同。M03
capacity / size
容量 / 单元大小		每个簇允许的大小上限；簇的大小是其中单元大小之和。按节点个数平衡不等于按面积平衡；单元面积可以不同。M04
contraction / coarsening
收缩 / 粗化		把两个簇合成一个超节点：它们之间的边变成内部边，与外部的平行边权重相加。内部边只是不再计入 cut，原电路的连线并没有被删除。M03
target K
目标簇数 K		希望最终得到的簇数；达到 K 就停止合并。“达到 K”与“满足容量”是两件独立的事，不能用一个换另一个。M03 M04
label
标签		LP 中节点当前所属群体的记号；节点名字不变，标签会变。不是节点身份；RW 中的“延迟标签 l(v)”是一个数，含义完全不同。M05
asynchronous / synchronous
异步 / 同步更新		异步：算出新标签立即写回；同步：整轮读同一张旧快照，轮末一起提交。同一张图换更新方式，结果和是否停止都可能不同。M05
stable / cycle / limit
稳定 / 周期 / 上限		整轮零变化为 stable；标签状态重复出现为 cycle；达到轮数上限为 limit。只有 stable 可以叫“收敛”。M05
sweep
扫描		谱二分中沿排序逐个位置试切；LP 中有时也把“一轮遍历”叫 sweep。两个用法不同，课程里谱方法说“扫描切分”，LP 说“一轮”。M06
Laplacian L = D − A
拉普拉斯矩阵		度矩阵减邻接矩阵；对称、每行和为 0；xᵀLx = Σ w(u,v)(x_u − x_v)²。这里的 D 是度矩阵，不是 RW 的跨簇延迟 D。M06
Fiedler vector
菲德勒向量		第二小特征值 λ2 的特征向量，给每个节点一个数用于排序。λ2 简并时不唯一；正负号不保证两侧平衡，也不能代替扫描。M06
gain
收益		一次交换或移动前的 cut 减去之后的 cut。收益 ≤ 0 的步骤也可以作为试探；是否保留由最佳前缀决定。M07 M08
pass / lock
一轮 / 锁定		一轮改进中，每个节点最多动一次，动过就锁定。下一轮开始时全部解锁；锁定不是永久不可改。M07
best prefix
最佳前缀		一轮试探序列中，连续保留前 k 步使累计收益最大；k = 0（空前缀）合法。不是任意挑几个正收益步；必须是从头开始连续的一段。M07 M08
trial / accepted
试探 / 接受		试探状态是一轮中途的临时分组；接受状态是按最佳前缀回退后真正采用的分组。试探时 cut 可以暂时变差。M07
balance constraint
平衡约束		限制两侧大小的规则：KL 固定两侧人数；FM 允许两侧人数差在窗口内；谱二分声明比例窗口。按人数平衡不等于按面积平衡。M06 M07 M08
from-side / to-side terms
FS / TE		FM 的收益分解：v 是某 net 在本侧唯一引脚则 +w（FS）；某 net 在目标侧没有引脚则 −w（TE）。二端图上 FS−TE 等于外部边权减内部边权。M08
DAG / PI / PO
有向无环图 / 主输入 / 主输出		组合电路的信号沿有向边流动且不成环；PI 是没有输入的源，PO 是输出端。无向五节点图没有方向和时序，不能承担 RW 的延迟语义。M09
inter-cluster delay D
跨簇延迟 D		RW 模型中每条跨簇连线增加的固定延迟；簇内连线为 0。和拉普拉斯矩阵里的度矩阵 D 无关。M09
replication / logicalId and instanceId
复制 / 逻辑与实例		同一个逻辑节点可以在多个簇里各放一个物理实例，每个实例的输入都要完整。复制有面积代价，不是免费的；一个“节点→簇”的映射表示不了复制。M09
TTS
文本转语音		可选的影片配音工具。本课程首版为中文字幕、无配音。教师课堂关键词里出现 tts，不等于要求配音。
