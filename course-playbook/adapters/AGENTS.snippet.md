# Course production rules

This repository is a bilingual (Chinese / English) algorithm course built in the Learning Clustering house
style. For any work on course content, pages, engines, challenges, code labs, films or slides:

1. Read `course-playbook/SKILL.md` first and follow it as standing instructions.
2. Read the reference file for the area you touch:
   - pages and data formats: `course-playbook/reference/01-course-anatomy.md`
   - how much and how deep: `course-playbook/reference/02-volume-and-depth.md`
   - films: `course-playbook/reference/03-film-style.md`
   - design, i18n, labs, code lab: `course-playbook/reference/04-site-design.md`
   - process and working with the author: `course-playbook/reference/05-workflow.md`
   - correctness and tests: `course-playbook/reference/06-quality-and-tests.md`
   - known pitfalls: `course-playbook/reference/07-lessons-learned.md`
3. Use the step prompts in `course-playbook/prompts/` and the checklists in `course-playbook/checklists/`.
4. Keep `implementation-plan.md`, `decision-log.md`, `implementation-log.md` and `handoff-state.md` current.
5. Every number shown to learners comes from the course's own engine; run the tests before you finish.
