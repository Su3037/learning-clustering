# Module acceptance checklist

Copy per module. Tick only what you actually checked; write "skipped" with a reason otherwise.

## Content
- [ ] `module.md` outline exists and was written before the page and films
- [ ] 6 objectives, each linked to lesson anchors, challenges, slides and code lab (crosswalk complete)
- [ ] Problem statement has all six fields: input, output, objective, constraints, assumptions, stop
- [ ] Lesson: 6–8 sections, hand-checkable example first, tables of real values, harder case, counterexample
- [ ] Terms defined (term cards) before first use; glossary updated
- [ ] Pseudocode with a comment per line, matching engine and Python
- [ ] Background with a real citation; application with honest limits; limitations list
- [ ] 4–5 common mistakes: wrong / why / counterexample with engine numbers / fix
- [ ] Credits: author, site, repo, pinned commit, what was kept, licence note (incl. music)
- [ ] Foundations / previous module linked instead of repeated

## Correctness
- [ ] Engine passes regression, property and source-error tests
- [ ] JS ↔ Python cross-check passes
- [ ] Every number in lesson, slides, challenges, mistakes and films comes from the engine

## Interaction
- [ ] Lab: step / back / to end, arrow keys, pseudocode highlight, state panels, parameter controls, export
- [ ] 6–7 challenges, ≥ 3 categories, Intro → Practice → Stretch, two hints, why, targeted feedback
- [ ] Code lab: two core functions, 5–8 named checks; reference passes; starter INCOMPLETE; visualiser runs

## Media
- [ ] Four films (科普, 精讲, 进阶, 实验演示) in zh and en; popular film hook is about this algorithm
- [ ] Every film: 0 reading violations, `why` paragraph, chapters, transcript, VTT, poster
- [ ] Slides: 11–14, numbered `Module 0X · title · p/total`, transcript under the slide, PDF + PPTX with notes

## Languages and pages
- [ ] English page complete, no leftover Chinese except term pairs and names
- [ ] Desktop and 375 px pass in both languages; no console errors
- [ ] Deep links (`#lab`, `#slides`, `#slide-<id>`) work after refresh

## Sign-off
- [ ] Review pack shown to the author (screenshots, contact sheets, film links); sign-off recorded in the decision log
